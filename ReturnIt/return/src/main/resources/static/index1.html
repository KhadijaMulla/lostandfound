How it works

Report

Post an item as lost or found with a title, location and description.

Claim

If you recognise a found item, send a claim with your name and a message that proves it is yours.

Review

An administrator reviews each claim and approves or rejects it.

Return

Once the handover happens, the claim is completed and the item is marked returned.

About ReturnIt

ReturnIt is a hackathon project: a simple, shared place where lost things and found things can meet. Everything shown comes from a real backend (Spring Boot and MySQL); nothing on this site is pre-filled or made up.

Our goal is modest: make it easier for honest people to return what isn't theirs, and for owners to get it back with a clear, reviewed process.

We don't publish statistics or testimonials because we don't have any yet.
